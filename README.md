# FlowMeter Mission Manager – v2

نسخه عملیاتی مدیریت مأموریت‌های نصب فلومتر التراسونیک.

## تغییرات این نسخه
- کلیک روی نام چاه در جزئیات مأموریت و ورود مستقیم به صفحه چاه
- تقویم شمسی برای تاریخ‌های مأموریت و نصب/بازدید، با ذخیره تاریخ استاندارد میلادی در دیتابیس
- اصلاح چرخه عمر نقشه Leaflet و جلوگیری از ماندگاری بصری نقشه روی صفحات دیگر
- نمایش Marker واقعی و جلوگیری از تغییر مختصات در حالت مشاهده
- GPS و جابه‌جایی Marker فقط در فرم ثبت/ویرایش
- انتخاب عکس نصب از گالری یا دوربین
- جلوگیری از ساخت نصب اولیه تکراری؛ ثبت مجدد نصب اولیه همان رکورد را به‌روزرسانی می‌کند
- نمایش واقعی توضیحات، عکس‌ها و ویس‌های هر نصب/بازدید
- چک‌باکس «نیازمند پیگیری و مراجعه مجدد»
- کارت‌های داشبورد قابل کلیک
- حذف بخش عمومی «رسیدها و فایل‌های مأموریت»
- غذا: یک مبلغ + عکس رسید/فاکتور
- رفت‌وآمد: مسیرهای متعدد با مبلغ + عکس‌های رفت‌وآمد
- سایر هزینه‌ها: عنوان + مبلغ تکرارشونده + عکس‌ها
- حفظ ساختار بدون Login و بدون RLS مطابق نیاز پروژه

## Supabase migration
اگر دیتابیس نسخه قبلی را قبلاً ساخته‌ای، فقط این فایل را یک بار در SQL Editor اجرا کن:

`supabase-migration-v3.sql`

فایل `supabase-schema.sql` برای نصب تازه است و نباید روی دیتابیس دارای داده دوباره اجرا شود.

## GitHub Pages
فایل‌های پروژه را در ریشه Repository قرار بده و `.github/workflows/deploy.yml` را نگه دار.
`node_modules` را آپلود نکن؛ GitHub Actions خودش وابستگی‌ها را با `npm install` نصب می‌کند.


### اصلاحات نسخه جدید
- عکس‌های غذا و سایر هزینه‌ها با `owner_id` به رکورد دقیق هزینه متصل می‌شوند.
- نوع MIME واقعی فایل‌های صوتی/تصویری هنگام آپلود در Storage حفظ می‌شود تا پخش ویس روی موبایل پایدارتر باشد.
- دکمه حذف کارت‌های چاه و مأموریت به پایین کارت منتقل شده تا روی وضعیت کارت نیفتد.
- دکمه Back مرورگر/گوشی حالا بین صفحات داخلی سایت حرکت می‌کند و از سایت خارج نمی‌شود.
- فایل `supabase-migration-v6.sql` برای تکمیل ساختار رسانه‌ها و Storage اضافه شده است. این Migration را یک‌بار در SQL Editor پروژه Supabase اجرا کنید.


## نقشه نشان

صفحه «چاه‌ها» از SDK رسمی وب نشان استفاده می‌کند و در صورت وجود کلید، مارکرها و خوشه‌بندی چاه‌ها را روی نقشه نشان نمایش می‌دهد. برای GitHub Pages یک Secret با نام `NESHAN_API_KEY` در مخزن بسازید؛ workflow آن را به `VITE_NESHAN_API_KEY` تزریق می‌کند. بدون این کلید، نقشه برای جلوگیری از ازکارافتادن سایت به OpenStreetMap برمی‌گردد. راهنمای رسمی نشان نمونه استفاده از SDK وب Leaflet را ارائه می‌کند و مخزن رسمی NeshanMaps نیز SDKهای React را منتشر کرده است.

## خروجی ZIP تصاویر

در صفحه «گزارش‌ها» می‌توانید چاه‌ها را انتخاب کنید و همه عکس‌های هر چاه را در یک ZIP دریافت کنید. نام فایل‌ها بر اساس نام چاه و در صورت چند عکس، با «تصویر 1»، «تصویر 2»، ... ساخته می‌شود.
